# Constructor Knowledge — review snapshot

This repository holds a **static snapshot of a website that is still being
built**, published only so reviewers can look at it without needing anything
installed. It is not the live Constructor Knowledge site and it is not finished.

**Please do not treat anything here as published or final.** In particular:

- The **imprint and privacy pages contain placeholder text**, not real legal
  copy. They exist so the layout can be reviewed and must not be read as
  Constructor Knowledge's actual legal notices.
- Some page copy and all SEO metadata are **drafts awaiting approval**.
- The news feed is a **snapshot** taken when this was exported, not a live feed.

The site is set to `noindex` and this repository ships a `robots.txt` that
disallows all crawlers, so it should not appear in search results.

## What this is, technically

A WordPress + Elementor site exported to plain HTML, CSS, JS and images — no
PHP and no database. Everything interactive on the site (the news filters and
pagination, the partner strip, the ecosystem explorer) is client-side, so the
static copy behaves like the real thing.

Regenerated from the source project with a single command; it is generated
output, so **edits made here would be overwritten** and should go to the source
project instead.
